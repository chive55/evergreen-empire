# Evergreen Empire

A touch-friendly idle browser game. Grow from a village into an empire, then found a new dynasty for permanent income bonuses.

## Play

Open `index.html` in a modern browser. No installation, build step, or external dependencies are required.

- Tap to collect tribute.
- Buy villages, soldiers, and territories for passive income.
- Purchase trade charters and royal decrees to boost earnings.
- Earn up to eight hours of offline income.
- Prestige for crowns; each crown adds 25% to all income.
- Autosave every ten seconds, with manual save and reset controls.

Progress is stored locally in your browser. Clearing browser data removes your save.

## Files

- `index.html`: complete game, including CSS and JavaScript.
- `evergreen-empire-x.png`: X promotional share card.
- `evergreen-empire-itch.png`: itch.io promotional cover.

The promotional artwork is AI-generated concept artwork, not a gameplay screenshot.

## Validation

HTML structure and JavaScript syntax were checked. Core mechanics were tested for tapping, purchases, escalating costs, passive income, prestige, saving, reset, offline limits, and corrupt-save recovery.

The game includes embedded city-growth artwork with a progress indicator that advances from village to town when you recruit a soldier, and to city when you acquire a territory. Existing browser saves remain compatible.
